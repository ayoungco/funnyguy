# www.fgcomics.com (2005)

This is the source code for the website www.fgcomics.com, which was active in 2005. The website was built using HTML, CSS, and JavaScript, and it featured a collection of comics created by various artists.

Notable:

- phpBB 2.0.13 forum software with custom modifications and graphics

## Trivia

- the first forums were trial on invision power board which BZPower used, I was an active member there and modeled this forum after their ranking system in phpBB 2.0 and was able to host locally on my own server. probably the first legit web application I had I hosted myself
- I experimented with javascript for theme switching by changing the active stylesheet
